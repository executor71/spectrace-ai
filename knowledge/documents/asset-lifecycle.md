# IT 자산 상태와 재고 관리 규칙

## 자산 등록과 관리번호
가상 자산관리 시스템의 자산 담당자는 노트북, 모니터, 휴대전화에 고유한 자산번호를 부여한다. 자산번호와 제조사 일련번호는 중복될 수 없다. 신규 등록 시 자산 상태는 AVAILABLE(대여 가능)이다. 분실 신고된 장비나 폐기된 장비를 신규 재고로 다시 등록하지 않는다. 구매일, 장비 종류, 관리 부서, 일련번호는 필수 입력이다.

## 대여 가능한 재고 판정
임직원에게 지급할 수 있는 재고는 자산 상태가 AVAILABLE이고 활성 대여 기록이 없는 장비다. RESERVED(예약), ON_LOAN(대여 중), MAINTENANCE(수리 중), LOST(분실), RETIRED(폐기) 상태는 대여할 수 없다. 예약은 승인 완료부터 실물 지급까지 유효하다. 대여 화면의 재고 조회 결과만 신뢰하지 않고 승인 트랜잭션에서 최신 상태를 다시 확인한다.

## 수리와 폐기 상태 전이
반납 검사에서 이상이 발견되면 자산을 MAINTENANCE로 전환한다. 수리 완료와 기능 점검 통과가 기록된 후에만 AVAILABLE로 복구한다. RETIRED로의 전이는 자산 관리자만 수행하며 폐기 사유를 남긴다. 활성 대여나 미완료 반납 검사가 있으면 폐기를 거부한다. 이미 폐기된 자산은 대여 가능 상태로 되돌릴 수 없다.
