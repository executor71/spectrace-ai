# 자산관리 접근 권한과 감사 정책

## 역할별 조회 범위
EMPLOYEE는 본인 대여와 자기 조직의 가용 재고만 조회한다. DEPARTMENT_MANAGER는 자기 부서 직원의 대여 신청과 연체 상태를 조회한다. ASSET_ADMIN은 자산 등록, 지급, 반납 검사, 폐기를 담당한다. 요청의 departmentId 값만으로 접근을 허용하지 않고 로그인 계정의 조직과 비교한다. 타 조직 접근은 ACCESS_DENIED로 차단한다.

## 대여 내역 CSV 다운로드
대여 이력 CSV 내보내기는 ASSET_ADMIN만 허용한다. 부서장과 일반 직원은 CSV 다운로드를 할 수 없다. 직원 이메일, 전화번호, 주소는 파일에서 제외하고 직원번호는 끝 네 자리만 표시한다. 파일 링크는 10분 후 만료되며 다운로드 요청자, 필터 조건, 생성 시각을 감사 로그에 남긴다.

## 감사 로그와 민감정보 처리
승인, 반려, 지급, 반납 검사, 폐기는 변경 전후 상태와 행위자, 서버 시각, 요청 ID를 기록한다. 비밀번호, 인증 토큰, 원본 개인정보는 감사 로그에 저장하지 않는다. 일반 사용자는 감사 로그를 수정하거나 삭제할 수 없다. 업무 오류 응답에는 내부 SQL, 데이터베이스 주소, 스택 트레이스를 포함하지 않는다.
