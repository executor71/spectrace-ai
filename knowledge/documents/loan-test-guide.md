# 대여와 반납 기능 검증 가이드

## 대여 승인 권한 테스트
서로 다른 두 직원과 부서장을 합성 계정으로 준비한다. 부서장은 같은 부서 직원의 신청을 승인할 수 있어야 한다. 일반 직원, 타 부서 부서장, 신청자 본인의 승인은 HTTP 403으로 거부되어야 한다. 거부된 요청은 신청 상태와 자산 상태를 변경하지 않아야 한다. 자기 승인 오류 코드는 SELF_APPROVAL_FORBIDDEN으로 확인한다.

## 동시 대여 승인 테스트
AVAILABLE 장비 한 대와 서로 다른 두 직원의 PENDING_APPROVAL 신청을 준비한다. 두 승인 요청을 동시에 전송한다. 정확히 하나는 HTTP 200으로 성공하고 다른 하나는 HTTP 409 ASSET_NOT_AVAILABLE이어야 한다. 최종 자산은 RESERVED이고 해당 장비의 승인된 신청은 한 건이어야 한다. 두 건 모두 성공하거나 장비가 AVAILABLE이면 실패다.

## 반납 연체 경계값 테스트
반납 예정일 당일, 하루 뒤, 월말과 윤년 2월 경계를 각각 확인한다. 예정일 당일 반납 접수의 overdueDays는 0이고 다음 날은 1이다. 반납 검사 완료가 늦어져도 접수 이후 날짜는 연체에 더하지 않는다. 파손 반납은 MAINTENANCE, 정상 반납은 AVAILABLE인지 별도로 확인한다.
