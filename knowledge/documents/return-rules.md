# 장비 반납 및 연체 처리 규칙

## 반납 접수와 검사 대기
현재 대여자 또는 자산 담당자만 반납 접수를 할 수 있다. 반납 접수만으로 재고를 AVAILABLE로 변경하지 않는다. 반납 건은 INSPECTION_PENDING으로 생성되고 자산은 검사 완료 전까지 새로운 대여에서 제외한다. 본체, 충전기, 부속품의 반납 여부를 기록하며 접수일과 담당자를 보관한다.

## 파손 장비의 수리 전환
자산 담당자는 반납 장비의 외관과 작동 상태를 검사한다. 파손 또는 기능 이상이 있으면 검사 결과를 DAMAGED로 기록하고 자산 상태를 MAINTENANCE로 바꾼다. 사진과 파손 설명은 필수이며 정상 재고로 바로 돌릴 수 없다. 이상 없는 장비는 검사 결과 PASSED와 함께 AVAILABLE로 전환한다.

## 반납 기한과 연체 계산
반납 예정일 다음 날부터 실제 반납 접수일까지 달력 일수로 연체일을 계산한다. 예정일 당일 접수는 연체가 아니다. 반납 검사에 걸린 시간은 임직원 연체일에 추가하지 않는다. 매일 오전 9시에 연체자와 소속 부서장에게 안내한다. 분실 신고가 접수된 경우 연체 안내 대신 분실 처리 절차로 전환한다.
